# 🥚 洛克王国孵蛋数据管理系统 (Roco Incubator Table)

> **全属性宠物、蛋组和性格匹配中心，专为洛克王国孵蛋高端玩家打造的桌面数据管理系统。**  
> 支持本地持久化自动保存、可拖拽排序对齐、一键导出防盗长图以及智能 3V 蛋自动统计。

---

## ✨ 核心特性

### 🪺 蛋窝与需求中心

- **🎮 高效双向匹配筛选**：支持按宠物名、性格、蛋组、牌子、窝点状态以及是否极限等条件进行多维复合检索，快速定位最匹配的父母。
- **🎭 精灵多形态支持与极简交互**：
  - **全形态智能匹配**：系统支持精灵多种外观形态（如冬羽雀的四季形态、丢丢的各种地形形态等）。通过识别带下划线的特定命名（如 `冬羽雀_春天的样子`），底层重构的匹配模块能够自动剥离出基础名 `冬羽雀` 来关联其属性与蛋组。
  - **多点位极简交互**：
    - **蛋窝卡片**：如果该精灵拥有多形态，其大头像左下角将优雅地展示出毛玻璃质感的形态切换下拉框。
    - **表格行编辑**：在编辑表格视图下，精灵名称输入框右侧也新增了形态选择下拉菜单，方便玩家快速切换。
    - **发布需求表单**：在换蛋中心的需求发布表单中，只要输入有形态的精灵，输入框右侧即刻渲染对应的形态选择下拉框，并实现头像预览联动切换。
    - **需求看板卡片**：在发布到看板的卡片上，同样支持行内快速下拉切换，更新状态。
  - **升级进化链保留形态**：不管是表格行升级、蛋窝卡片升级还是换蛋发布时，系统在自动将其升级为最高阶形态的同时，将完美保留后缀形态。
  - **长图导出自动剔除**：形态切换下拉框绑定了 `.action-buttons` 过滤样式，当用户一键导出防盗长图时，所有切换下拉框将智能隐形，确保最终导出的长图美观无暇。
- **🔀 智能拖拽物理排序**：基于 `@dnd-kit` 开发的表格行拖拽系统，玩家可以通过左侧手柄自由调节宠物物理展示顺序，重新排布孵蛋优先级。
- **🧬 智能 3V 蛋检测与计数**：
  - 系统会自动对比父母的"三围"（生命、物攻、速度等）属性配置。
  - **当父母的三围属性完全一致时，系统会自动将该数据行高亮，并标记为「3V蛋」**。
  - 顶部统计面板会实时显示「3V蛋」的总只数，极大提升培养效率。

### 👪 父母本管理中心

- **🃏 精美父母本卡片**：为每只父精灵或母精灵创建独立管理卡片，卡片内含：
  - **精灵头像**：自动加载对应精灵高清 Sprite 图，支持多形态下拉切换。
  - **属性系别徽章**：精灵属性以带颜色背景的系别图标展示，视觉直观。
  - **📏 标准身高体重参考**：引入全图鉴数据库（`src/pets_data.json`），自动展示该精灵的标准身高（🔩 Ruler 图标）与体重范围（⚖️ Weight 图标），支持多形态差异化匹配（如鸭吉吉的蓬松形态与紧实形态体重区间各自对应）。
  - **📍 物理存放位置通栏**：将游戏内物理存放位置 Badge 平铺在卡片底端通栏渲染，让玩家一眼看清、绝不截断。
  - **牌子 / 身高 / 体重 / 性格 / 三围**：全面覆盖孵蛋所需核心属性，支持实时编辑与持久化存储。
  - **配组勾选**：左上角配组复选框，可快速标记该精灵是否纳入当前配组计划。
- **🤖 智能繁育配对联动**：
  - **进化链分组合并**：改以产出蛋品种（`eggSprite`）作为分组键对符合筛选的配对进行重构。同一进化链同样子的母本（例如波波拉与朵拉拉）繁育相同精灵蛋时将合并在同张卡片中，避免了品种重复冗余。不同形态（样子的后缀不同）产生的蛋不同，自动隔离在两个独立大卡片下渲染，杜绝了形态混淆。
  - **双亲左右联动切换**：合并后的卡片提供 Chevron 左右切换按钮及指示角标，用户可在当前精灵蛋下的多个 (father, mother) 双亲配对组合间进行一键切换，卡片两端父母头像、系别、名字、三围、性格、存放位置以及一键导入数据均联动刷新。
  - **一键导入筛选后配对**：顶部的一键导入按钮已改造为深度联动筛选状态，点击时只将当前页面经过筛选框过滤并勾选的配对组合导入到蛋窝中，不再强行导入其他未筛选出的隐藏配对。

### 🌐 通用功能

- **💾 本地免安装自动持久化**：
  - 系统会在后台默默保护您的心血。任何数据的增删改动都会即时自动保存到本地物理文件夹下的 `roco_egg_data.json` 中。
  - 底部存储路径展示清晰，点击 **「修改」** 按钮可随意指定本地存盘文件夹（如果新文件夹下已有数据则会自动读取，无数据则自动同步写入），完美满足备份需求。
- **📸 一键防盗长图导出**：
  - 点击底部的 **「一键导出长图」** 按钮，系统会智能隐藏所有拖拽手柄、操作按钮和筛选栏等干扰元素，直接渲染为纯净的高清表格长图。
  - **解除分页限制**：导出前 React 会感知导出状态，临时解除全站所有 Tab（蛋窝中心、父母仓库、精灵蛋库）的分页 slice 截取限制，Canvas 长图生成后自动回复为原分页排版。
  - 支持后台自由配置**水印内容、水印大小与透明度**，在导出的长图背景中会渲染重叠倾斜的防盗水印，发群里、贴吧交流时再也不怕被盗图。
- **📱 全设备响应式适配**：
  - 完整适配手机端（320px–480px）到 PC 端（1200px+）的全视口范围，无需下载 App 即可在手机浏览器流畅使用。
  - 蛋窝卡片采用移动端垂直堆叠 / PC 端网格双轨布局，确保在任意屏幕尺寸下均无文字折行重叠与元素变形。
  - `Autocomplete` 下拉浮层接入 `visualViewport` API，智能感知软键盘弹出后的实际视口高度，自动翻转到键盘上方弹出，杜绝输入框被遮挡。
  - 长图导出采用 1200px 离屏渲染物理隔离，移动端响应式改动**不影响**导出画质，始终输出高保真 PC 端排版。
- **ℹ️ 关于 & 致谢弹窗**：Banner 右侧提供「关于 & 致谢」按钮，内含数据来源链接、特别鸣谢信息及作者联系方式。

## 🔌 游戏数据自动抓取与导入指南 (SQLite & 直连 API 导入)

为了避免繁琐的精灵手动录入流程，本系统支持一键直连解密并导入您在游戏里的“宠物箱与所有仓库”中的精灵资产数据。

### 1. 前置条件安装
1. **安装网卡捕获驱动 Npcap**：
   - Windows 的网卡抓包模式依赖于 Npcap 驱动。请访问官网下载安装：[Npcap 官网 (npcap.com/#download)](https://npcap.com/#download)，或直接运行项目根目录下的本地安装包 [npcap-1.88.exe](npcap-1.88.exe)。
   - **安装注意**：必须使用**管理员权限**运行安装包，且在安装过程中**务必勾选 "Install Npcap in WinPcap API-compatible Mode"**（以 WinPcap 兼容模式安装）。
   - **排错建议**：安装或重新安装后建议重启工具；如果仍无法看到网卡，可以尝试重启 Windows 操作系统。
2. **配置数据抓取助手**：
   - 玩家**无需手动运行**数据抓取助手。只需将 [roco_helper-v3.2.2.exe](dist-electron/roco_helper-v3.2.2.exe)（存放于 `dist-electron/` 目录）复制并放置在本系统的 `.exe` 可执行文件同级目录下。
   - 当本系统启动时，会自动在后台静默运行该抓取助手来监听并解密游戏数据。

### 2. 精灵一键导入步骤
1. **启动管理系统**：先打开 `洛克王国孵蛋数据管理系统.exe`（软件将自动在后台静默拉起数据抓取助手进程）。
2. **启动并进入游戏**：再打开洛克王国游戏客户端并登录角色。在游戏内打开 **“宠物箱”** 或者是 **“仓库”**，此时数据抓取助手会自动捕获封包并建立本地解密数据库。
3. **发起导入面板**：在本系统的 **“父母本管理中心”** 仓储界面，点击顶部的 **「从游戏导入数据」** 按钮。
4. **选择数据库直连**：在弹出的导入浮层中，点击 **「本地数据库直连」** 选项。
5. **一键同步数据**：选择要导入的角色账号 UID 昵称，点击 **「一键读取数据导入」** 即可秒级拉取全部最新的宠物三围、性格、存放位置等个体数据。

## 🛠 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| **语言** | TypeScript / TSX | 前端主要逻辑与 React 组件 |
| **语言** | JavaScript (CommonJS `.cjs`) | Electron 主进程与预加载脚本 |
| **语言** | Python | 爬虫脚本，用于抓取游戏基础数据 |

## 🚀 开发者快速启动指南

### 1. 本地开发调试
1. 确保安装了 **Node.js** 环境。
2. 克隆项目或在工作区根目录下执行：
   ```bash
   npm install
   ```
3. 启动 Vite 本地开发服务器：
   ```bash
   npm run dev
   ```
4. 启动 Electron 桌面调试环境：
   ```bash
   npm run electron:start
   ```

### 2. 构建与打包
- **静态资源编译**（生成静态网页）：
  ```bash
  npm run build
  ```
- **Windows 便携版 EXE 打包**（一键生成自带 `001.ico` 图标的绿色便携版程序）：
  ```bash
  npm run electron:build
  ```
  打包成功后，可在根目录下的 `dist-electron/` 目录中找到 **`洛克王国孵蛋数据管理系统 6.0.0.exe`**。

## 📅 最近更新日志 (Changelog)

### v6.0.0 (2026-07-08)

#### 🧬 智能配对进化链分组合并
- **进化链分组合并**：改以产出精灵蛋（`eggSprite`）作为分组键进行合并分组。同一进化链同样子的母本（例如波波拉与朵拉拉）繁育相同精灵蛋时将合并在同张卡片中，避免了品种重复冗余。不同样子的精灵生出来的蛋不同，自动隔离在两个大卡片下渲染，杜绝了形态混淆。
- **一键导入只导入当前筛选**：智能配对一键导入按钮（`handleImportPairingsToNest`）正式联动了当前筛选，只有在页面可见且被勾选的繁育配对会被导入。

#### 👪 父母本仓库与交互体验细化
- **位置通栏重排**：彻底移除了原本在父母本卡片左侧窄列极易因空间局促而被折叠截断的 `📍位置` 标签。在卡片底部以 100% 宽度重新排版为精美的底部毛玻璃通栏展示，一目了然。
- **蛋窝父母同性格筛选**：蛋窝中心筛选栏也新增了“父母同性格”勾选框。
- **现蛋数量智能零点初始化**：蛋窝卡片的状态被切换为“有现蛋”时，默认现蛋数量 `eggCount` 自动初始化为 `"0"`，且能自动识别原有状态防止误清空已有计数。
- **长图导出全量无分页**：一键导出长图（`handleExportLongImage`）在导出前，React 会感知 `isExporting` 状态，临时解除全站所有 Tab（蛋窝中心、父母仓库、精灵蛋库）的分页 slice 截取限制，Canvas 长图生成后自动恢复为原分页排版。
